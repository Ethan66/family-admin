# 测试用例

- 查询当前家庭的列表、ID、关键词、状态、分页；不发起写请求，不套用han/zc成员默认。
- 新增文本、标签、清单和已有图片引用；全空、超长、非法类型/状态/图片编号拒绝。
- 重复新增不重复创建，相同编号不同内容拒绝；超时保留待核实。
- 局部修改仅更新指定字段，保留原图片、清单、颜色和置顶；明确清空允许但不能使整条内容全空。
- 版本不符或目标不存在不发送PUT/DELETE；版本在读写间变化由后端409拒绝，不自动重试。
- 修改成功重试可返回原回执，不因当前版本已增加失败；删除成功重试不因目标已消失失败。
- 权限拒绝/5xx/超时不回复成功；固定家庭仍有效。
- 官方MCP客户端启动真实stdio子进程，使用本机模拟HTTP后端完成创建、查询、局部更新、删除和重复回执。
- 服务器仅验证工具发现、真实只读查询及非法输入拒绝，不写真实笔记。
