# 技术方案

版本0.7.0。在 `quick_notes.py` 集中定义严格的内容/局部修改模型及随身记业务混入，FamilyService复用现有认证、固定家庭和写入日志；server注册4工具，共16工具。

- 查询固定 `GET /quick-notes`，服务端返回当前家庭正常/归档记录；MCP可按ID、关键词、状态和分页筛选，返回total/has_more。
- 新增固定 `POST /quick-notes`，完整有效内容、status=ACTIVE、version=0。
- 修改固定 `PUT /quick-notes/{id}`；参数为ID、查询版本、局部changes。先命中已有请求回执，再查询版本并合并，仅更改明确字段，保留图片/清单等未提供内容。
- 删除固定 `DELETE /quick-notes/{id}?version={version}`，先命中防重回执再查目标及版本，不接受任意路径。
- 写入辅助函数允许只读preflight返回最终请求体：日志指纹使用稳定操作意图，实际请求使用校验后的完整笔记。原有preflight返回None的行为保持不变。
- 后端继续执行家庭/对象权限、图片有效性和版本原子校验。HTTP409明确提示重新查询，不自动升版本重试。

字段限制与Java一致：标题200字、正文10000字、20标签各30字、9图片、100待办各300字，颜色plain/sage/sand，状态ACTIVE/ARCHIVED。空字符串/空列表可以明确清空，修改字段不可为null。至少标题、正文、图片或待办一项非空。
