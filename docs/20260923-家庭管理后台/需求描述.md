# 家庭管理桌面端 — 需求描述

**首次日期**：2026-09-23  
**变更日期**：2026-09-24  
**需求来源**：当前目录 `产品文档/` 静态交互原型及本次对话确认内容

## 变更目标

保留现有 `server/` 和 `web/` 的代码与逻辑不变，新建独立的 Windows 桌面端 `desktop/`。桌面端替代后续 Web 使用场景，通过现有 Java 服务完成登录、家庭、收支和审计等联网业务，通过 Tauri 原生能力扫描和访问当前电脑的家庭资源。

首版支持 Windows 10 x64（1803 及以上），优先控制安装包体积。

## 用户与租户

- 一个家庭相当于一个租户，家庭间远端业务数据与本地索引均隔离。
- 超级管理员可管理家庭和成员账号，并只读查看所有家庭的远端业务数据。
- 家庭管理员可管理本家庭业务数据；不提供“家庭成员管理”页面。
- 普通成员只能修改或删除自己创建的远端业务数据。
- 本地资源按 `familyId` 分目录保存索引，文件本身不上传、不复制，其他电脑不可见。

## 桌面端功能

1. 登录、退出、个人资料、修改密码。
2. 家庭概览和收入支出，沿用现有 Java 接口。
3. 超级管理员家庭管理、跨家庭只读查看和审计日志，沿用现有 Java 接口。
4. 照片管理：选择一个或多个目录、递归扫描、网格展示和应用内预览。
5. 影片管理：选择目录、递归扫描、搜索和调用系统默认播放器打开。
6. 学习笔记：选择目录、递归扫描、搜索及 Markdown/TXT 只读预览；不做新增、编辑。
7. 试卷管理：选择目录、递归扫描，预览图片或 PDF。
8. 重新扫描时以磁盘现状更新 JSON 索引，已删除或移动的旧路径从索引移除。

## 支持格式

| 资源 | 扩展名 |
| --- | --- |
| 照片 | `.jpg`、`.jpeg`、`.png`、`.webp`、`.gif` |
| 影片 | `.mp4`、`.mkv`、`.avi`、`.rmvb` |
| 学习笔记 | `.md`、`.markdown`、`.txt` |
| 试卷 | `.jpg`、`.jpeg`、`.png`、`.webp`、`.gif`、`.pdf` |

扩展名匹配不区分大小写。不在白名单内的文件不进入索引。

## 技术与存储约束

- 桌面端目录为 `desktop/`，技术栈为 Tauri 2、Rust、Vue 3、TypeScript、Element Plus、UnoCSS。
- 使用 Pinia 管理状态、Vue Router 管理页面、Axios 调用现有远端 Java 服务。
- 本地索引保存到 `%APPDATA%/FamilyAdmin/families/<familyId>/resource-index.json`。
- 索引记录扫描根目录、绝对文件路径、名称、类型、大小、修改时间和扫描告警；不保存文件内容。
- 不修改 `server/` 和 `web/` 的现有业务逻辑，桌面端的本地资源模块不调用原有照片、影片、笔记和试卷资源接口。
- 登录页不展示服务地址输入框；Java 服务地址由桌面项目环境变量 `VITE_API_BASE_URL` 统一配置。
- 开发环境默认使用 `http://localhost:8080`；生产构建必须配置 HTTPS 服务地址。
- 分支为 `v_1.0`，原始 `产品文档/` 保留不覆盖。

## 不在首版范围

- 学习笔记新增和编辑。
- 内置影片播放器、影片转码和缩略图生成。
- 文件上传、文件复制、移动、重命名、删除和云端同步。
- 本地资源跨电脑共享。
- 家庭用户侧成员管理页面。
- 预算、账单导入导出、消息提醒和第三方登录。
- macOS、Linux 和 32 位 Windows 安装包。

## 验收标准

- Windows 10 x64 1803 及以上可安装、启动和卸载。
- 安装程序采用 NSIS 当前用户安装；安装包目标不超过 30 MB（不含首次下载的 WebView2 运行时）。
- 用户可分别配置四类资源的一个或多个目录，扫描结果与磁盘现状一致。
- 本地文件不上传到服务端，本地索引不跨家庭混用。
- 照片、笔记和试卷可预览，影片可通过系统默认应用打开。
- 无权限目录、失效路径、损坏 JSON 和接口离线均有明确提示，单个错误不导致整次扫描崩溃。
- 桌面端类型检查、单元测试、Rust 测试和生产构建通过；`server/`、`web/` 不产生代码差异。
