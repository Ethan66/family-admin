# 家庭管理桌面端 — 测试报告

**需求名**：家庭管理桌面端  
**服务名**：desktop  
**分支**：v_1.0  
**验证时间**：2026-09-24  

## 变更摘要

- 新增 Tauri 2 + Vue 3 + TypeScript Windows 桌面端。
- 接入现有 Java 认证、概览、收支、家庭和审计接口。
- 新增按家庭隔离的本地 JSON 索引、目录扫描、路径验证和资源预览。
- 照片支持 JPG/JPEG/PNG/WebP/GIF；影片支持 MP4/MKV/AVI/RMVB；笔记支持 Markdown/TXT；试卷支持图片/PDF。
- `server/`、`web/` 本轮未修改业务代码。

## 配置提醒

- 生产登录地址必须使用 HTTPS。
- 首次在缺少 WebView2 的 Windows 机器安装时，需要网络下载 WebView2 bootstrapper。
- 正式发布前应在 Win10 x64 干净机补做 DT-030，并使用实际 Java 服务完成登录和四类真实文件验收。
