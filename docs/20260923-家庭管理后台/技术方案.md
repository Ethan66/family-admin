**首次日期**：2026-09-23  
**变更日期**：2026-09-24  
**服务**：desktop（新增）、server（保持不变）、web（保持不变）  
**需求文档**：`docs/20260923-家庭管理后台/需求描述.md`

## 方案结论

选择 Tauri 2 + Vue 3 + TypeScript，新建独立 `desktop/`，不复用 `web/src`。Element Plus 按需引入，UnoCSS 负责布局与原子样式。Tauri 使用 Windows WebView2 渲染页面，Rust 负责目录选择、文件扫描、索引读写和调用系统默认应用。

### 备选方案

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| Electron + Vue | 不采用 | 自带 Chromium，安装体积明显更大 |
| Tauri + Vue + Rust | 采用 | 包体积较小，原生文件能力清晰，可继续使用 Vue/TS/Element Plus |
| C# WPF/WinUI | 不采用 | 偏离已确认的 Vue/TS 技术栈，需要重做完整 UI 工程体系 |

## 本地资源设计

### Rust 命令

- `select_scan_roots(kind)`：调用系统目录选择器，可追加一个或多个根目录。
- `load_resource_index(family_id)`：读取并校验当前家庭 JSON 索引。
- `scan_resources(family_id, kind, roots)`：递归扫描、过滤格式并更新该类型索引。
- `read_text_preview(family_id, path)`：只读加载 Markdown/TXT，限制单文件最大 2 MB。
- `open_with_default_app(family_id, path)`：使用系统默认程序打开影片或资源。
- `reveal_in_explorer(family_id, path)`：在资源管理器中定位文件。

图片和 PDF 通过受控的 Tauri 资源协议转换为可预览 URL；渲染层不获得任意文件系统读写权限。

### JSON 索引

路径：`%APPDATA%/FamilyAdmin/families/<familyId>/resource-index.json`

```json
{
  "schemaVersion": 1,
  "familyId": 12,
  "roots": {
    "photos": ["D:\\Family\\Photos"],
    "movies": [],
    "notes": [],
    "exams": []
  },
  "lastScannedAt": "2026-09-24T10:00:00+08:00",
  "resources": [
    {
      "id": "sha256-of-kind-and-canonical-path",
      "kind": "PHOTO",
      "path": "D:\\Family\\Photos\\2026\\a.jpg",
      "name": "a.jpg",
      "extension": ".jpg",
      "size": 102400,
      "modifiedAt": "2026-09-20T08:30:00+08:00"
    }
  ],
  "warnings": []
}
```

- `id` 根据资源类型与规范化绝对路径生成，不计算文件内容哈希，避免扫描大文件时产生额外 I/O。
- 每次扫描仅重建所选资源类型；其他类型索引保持不变。
- 写入采用“同目录临时文件 + 刷盘 + 替换”方式，避免进程中断留下半份 JSON。
- JSON 无法解析时先改名为 `resource-index.corrupt-<timestamp>.json`，再建立空索引并提示用户。
- 默认不跟随目录符号链接或 Windows junction，避免循环扫描和越出所选根目录。
- 遇到无权限目录记录告警并继续；已删除或移动的旧路径在重新扫描后移除。

## 页面与数据来源

| 页面 | 数据来源 | 说明 |
| --- | --- | --- |
| 登录、资料、修改密码 | Java server | 沿用现有接口 |
| 家庭概览、收入支出 | Java server | 沿用租户权限 |
| 家庭管理、跨家庭查看、审计 | Java server | 仅超级管理员可见 |
| 照片、影片、学习笔记、试卷 | 本地 JSON + 文件系统 | 不调用原资源接口 |

本地资源页面使用当前登录上下文中的 `familyId`。超级管理员查看本地资源前必须先选择目标家庭；不同家庭使用不同索引文件。

## 安全与错误处理

- 仅暴露上述自定义 Rust 命令，Tauri capability 使用最小权限，不开放通用文件写入。
- 所有路径在 Rust 层规范化，并校验仍位于已登记扫描根目录内。
- 文件仅只读访问；首版不提供删除、移动、重命名或写回原文件。
- JWT 只保存在当前应用会话中，关闭应用即清除；首版不提供“记住登录”。
- 本地绝对路径和索引内容不发送给 Java 服务。
- 接口异常不影响已登录会话内的本地扫描与浏览；首版不支持离线登录。
- 打开前再次检查文件存在性，不存在时提示重新扫描。

## 打包与兼容性

- 仅构建 Windows x64 NSIS 安装程序，采用当前用户安装，避免要求管理员权限。
- 最低支持 Windows 10 1803；该版本及以上通常已包含 WebView2。
- WebView2 采用 Tauri 默认 `downloadBootstrapper` 策略，不把离线运行时打入安装包。
- 安装包目标不超过 30 MB；构建后记录实际安装包和安装目录体积。
- 应用名称 `Family Admin`，本地数据目录固定为 `%APPDATA%/FamilyAdmin/`。
