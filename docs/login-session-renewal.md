# 登录状态与自动续期

- 后端默认有效期为 1440 分钟（1 天），可由 `JWT_ACCESS_TOKEN_MINUTES` 覆盖。
- 每次携带有效令牌并通过账号、家庭和密码版本校验的请求，都会在响应头 `X-Access-Token` 中返回一个新令牌，有效期从当前请求起重新计算。响应头已加入 CORS 暴露列表，桌面端可跨域读取。
- 桌面端收到成功响应后保存新令牌，下次请求使用新值。登录状态持久保存，关闭应用后再打开也能恢复；升级前仍在当前窗口内的会话会迁入持久存储。
- 续期只接受当前令牌发出的请求响应；退出、切换账号或较新续期完成后，旧响应不能覆盖当前会话。退出登录会清除两种存储，不保存密码。
- 连续 1 天没有有效访问则需要重新登录。过期令牌不能续期；账号停用、密码版本变化或家庭无效时仍会拒绝认证。不会通过后台定时访问保持永久登录。
- 旧令牌保留原来的过期时间，过期前访问新版后端、并由新版桌面端保存续期响应后，才能进入 1 天滚动有效期。
- 本次没有数据库结构变更。上线需要更新后端与桌面端；旧版桌面端不会保存续期响应头，不能实现自动续期。其他 API 调用方若需滚动续期，也需保存该响应头；MCP 现有自动重新登录机制继续适用。
