# 随身记实施计划

目标：按已确认的绿色桌面设计新增随身记，保留原有学习笔记入口。

架构：Vue 3 + TypeScript 页面调用独立 `/quick-notes` API；Spring Boot/MyBatis Plus 保存笔记及结构化清单、图片 ID 和标签。复用图片上传/鉴权下载接口。沿用家庭内可读、作者或当前家庭超级管理员可写的权限规则。

- [x] 后端：新增 quick_note 表和 Entity/Mapper/Payload/Response/Service/Controller。记录创建/更新时间及操作人，校验空笔记、图片所属家庭、状态和长度，以 version 条件更新防止覆盖并发修改。删除直接使用逻辑删除，并核对操作权限、家庭和版本；不提供回收站和恢复入口。
- [x] 桌面：新增类型、API、受保护图片组件和 QuickNotesView。默认两列网格、卡片高度 180px；提供新建、搜索、类型/标签筛选、置顶、编辑、清单、图片、归档和直接删除。右侧编辑区常驻，保存、取消、清空后回到空白新建状态；未保存的修改保留放弃确认。切换家庭清空并隔离过期响应。
- [x] 接入：新增 quick-notes 路由和独立导航入口，保持学习笔记功能不变。
- [x] 验证：后端先写安全/校验/并发测试；前端测试创建、编辑取消、筛选和切换家庭。按用户要求在提交前完成桌面全量测试、类型检查及后端全量测试与打包。

## 最终界面约定

- 顶部显示类型筛选、搜索和新建按钮，不显示大标题、快速记录区、排序选择器及全部笔记小标题。
- 右侧顶栏 36px，笔记标题 12.5px；正文占据剩余空间，待办和标签位于底部工具栏上方。
- 底部工具栏 46px，取消和保存按钮 30px；标签名称与输入框同一行。
- 不提供手动笔记颜色选择；卡片按图片浅蓝、待办浅黄、标签浅绿的优先级自动配色，普通文字白色。
