# 课程自动记课实施计划

**目标：** 用户确认课程结束后由服务器自动记录已上课、扣 1 节剩余课时，已记录或请假跳过，桌面端关闭不影响执行。

**设计：** 北京时间每天 09:00–19:00 在整点和半点检查，最后一次 19:00，不在 19:30 执行；启动完成即持久化首次启用时间，扫描进度持久化。仅处理启用后且课程创建/修改之后结束的课次，不追溯扣减旧历史。每次最多补扫七天，重启保留进度。课次操作使用课程行锁、课程日期唯一键及事务，自动记录与余额扣减同时成功或回滚。自动记录保存独立标志，审计创建人沿用课程创建人。

- [x] 先写测试：结束前不记录、结束后写入并扣 1、已上课/请假跳过、家庭或成员停用跳过、启用前课次跳过、检查点恢复。
- [x] V7 增加自动记录标记和任务检查点；新增全局候选查询及有效家庭关系校验。
- [x] 独立事务 Service 处理单个课次；定时 Job 分批处理并在全部成功后推进检查点。
- [x] 在独立临时数据库验证事务、重复执行、人工记录竞争及检查点。
- [ ] 打包、推送本次文件；复用服务器原容器备份/替换 JAR，检查任务初始化、接口和业务余额。

用户此前确认的课程、余额及人工上课记录保持原数据。仅从正式启用时刻开始自动处理，不创建生产演示课程。不启动或停止用户自行运行的本地后端。
