# MCP 收支银行卡和消费平台接入

**目标**：用户要求通过MCP记录收入、支出时可填写银行卡和消费平台。复用当前Java DTO已有可选 `bankCard`、`platform`，不修改后端、数据库和页面。

**规则**：MCP参数为可选 `bank_card`、`platform`，支持值严格与后端枚举一致。两字段独立，未明确不猜测；字段表示账户类别而非真实卡号。不填或空白时不发送该字段，保留旧请求指纹与防重兼容。填写时参与现有指纹，不允许相同请求编号换字段重复入账。收入、支出均适用。
