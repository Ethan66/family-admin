# MCP 存折只读查询实施计划

**目标**：基于最新源码 `550ec49`，MCP仅增加查询存折，不增加存折新增、编辑、删除工具或通用接口代理。

**设计**：新增一个 `list_passbooks` 只读工具，封装已有 `GET /api/passbooks`。默认当前绑定家庭全部成员（不套用zc或han默认），可明确指定家庭成员；支持存款日期起止、分页及后端四种白名单排序。返回明细、分页信息及后端全量本金/本息合计，注明合计不只是当前页。接口无银行筛选，不擅自增加此筛选或按当前页伪造全量统计。

**字段**：成员、银行、存款日、本金、年限、利率、到期日、总利息、本息合计、备注。日期过滤作用于存款日；到期日支持排序但没有独立到期日期过滤。利息和合计沿用后端值，不重新按利率估算。
