# 收支银行卡与消费平台实施计划

**目标：** 桌面端新增、编辑收支支持可选银行卡和消费平台，明细和统计支持同时按两项精确筛选。

**方案：** 银行卡选项为工商、农业、交通、光大、招商、支付宝、微信；消费平台选项为支付宝、微信、京东、美团、拼多多、淘宝、抖音。字段非必填、可以清空，历史数据保持空值。复用现有家庭隔离、成员规则和分页。服务端使用 `bankCard` / `platform`，数据库新增可空列 `bank_card` / `platform`。本次仅改桌面页面及其服务端，不扩展 Web 页面，不部署、不打包、不提交。
