# 课程表实施计划

**目标：** 按已确认图片新增桌面端课程表，上午/下午分区，卡片展示起止时间且无彩色竖边，支持上课记录持久化。

**架构：** Vue 3 页面通过独立 courses API 调用 Spring Boot；课程保存单次日期或每周重复规则，上课记录按课程和日期唯一保存，使用当前家庭与成员权限。历史记录保存课程名称和时间快照，不随课程编辑改变。

**范围：** 桌面端和服务端；不修改 Web、不部署、不提交现有工作区改动。上午按开始时间早于 12:00 分区，其余归下午。重复课程从起始日每七天出现一次。

- [x] 新增桌面端 `src/test/courses.spec.ts`，验证跨月周范围、周日归属、上午下午分区。
- [x] 新增服务端 `course/CourseServiceTest.java`，覆盖重复展开、家庭隔离、成员写权限、时间校验、记录幂等。
- [x] 新增 V4 迁移、课程与记录实体/Mapper、请求及响应类型、Service 和 Controller；按现有认证上下文限定家庭，使用真实成员关系。
- [x] 新增桌面端课程类型、API、日期辅助函数、课程表页；接入路由及侧栏。
- [x] 实现添加/编辑/删除课程、周次切换、成员筛选、上课/请假记录弹窗、记录历史分页及查看。
- [x] 执行相关单测、桌面端类型检查、后端编译及测试；临时 MySQL 库验证迁移、真实 Mapper 读写及记录幂等，不启动生产服务。

验收：空数据可创建课程；每周重复生成相应日期；上午下午区域内按时间排序；记录保存后刷新可读取；切换家庭丢弃旧响应并关闭编辑弹窗；历史记录能跨周查看。
