# 每日任务开发计划

基线提交：5ff0dba。用户确认按月历设计图开发，桌面端实现，不修改 Web，不自动部署或提交新增代码。

## 设计与边界

- 沿用现有 72px 侧栏、绿色主题、白色圆角面板。按用户裁剪图实现成员/状态筛选、日历/列表切换、月历、当天任务详情。不添加截图以外的统计卡片。
- 月历周一开始，完整展示相邻月份日期。日期格显示两条任务及剩余数量；选中日期展示所有符合筛选的任务。今天与选中日期有不同标识。
- 新建、编辑、删除、完成/取消完成持久化到后端。表单含标题、成员、开始日期、时间、分类、每天重复和备注。
- 每天重复从开始日期起生效，每天独立打卡；编辑和删除作用于整个重复任务，弹窗和确认消息明确提示。调整开始日期、重复规则或成员时清理该任务原打卡记录。
- 【2026-10-24 更新】所有用户可查看当前家庭全部成员任务，并为当前家庭的有效成员创建任务；成员筛选默认全部成员，支持选择其中一人。管理员可管理当前家庭全部任务，普通成员仅管理分配给自己的任务。后端始终校验家庭边界，未加入当前家庭的管理员本人不作为任务成员选项。
- 任务成员使用用户 ID，完成记录按任务 ID + 日期唯一。任务软删除，完成记录随模板一起隔离。查询区间最多 42 天。
- 这是新模块，增加 Flyway V3 建表脚本，不自动连接或修改生产数据库。

## 实施与验证

1. 先补日历日期计算和后端重复打卡/权限测试，记录失败。
2. 实现 V3、任务实体/Mapper、Service、Controller 和明确的前后端接口类型。
3. 实现月历组件、任务表单和每日任务页面，接入侧栏及路由；处理加载、空数据、家庭切换和过期响应。
4. 运行桌面相关测试及类型检查、后端测试/打包。因涉及数据库及权限，后端完整测试；验证迁移 SQL。针对月历视觉做浏览器检查，使用会话内测试数据，不向生产写入任务。
5. 输出测试报告，保留新增代码待验收。
