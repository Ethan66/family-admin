# 上课记录课时快照修复

## 已确认范围

仅修改后端及数据库迁移，保持接口字段 remainingLessons、totalLessons 和前端显示逻辑。

- 手工和自动记课在同一事务中先调整余额，再锁定科目余额并保存快照。
- 同科目不同课表共享余额行，快照读取使用当前读和行锁，防止并发串值。
- 新增请假记录保存当时未扣减的余额；已上课与请假互改时保存本次扣减或退回后的余额。
- 同状态重复保存只更新备注，保留原快照；后续设置余额或总课时不会改变历史快照。
- 旧记录和余额未设置的记录保留空值，前端显示 —/—，不使用当前余额回填。
- 快照描述处理时点的余额；补记过去课程不重算其他历史记录。

## 实施与验证

1. 回归测试先复现历史查询覆盖快照、手工/自动记课不保存快照、备注编辑丢失快照。
2. V13 为 course_record 增加两个可空字段；实体及 upsert 持久化快照，history 移除当前余额覆盖逻辑。
3. 验证首次扣减、请假退回、同状态重复保存、未设置余额、旧记录兼容及不同课表并发共享余额。
4. 使用独立本地临时 MySQL 实例验证迁移、真实 Mapper、事务回滚和并发，不连接或修改生产数据库。
