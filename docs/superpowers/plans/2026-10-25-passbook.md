# 存折页面实施计划

**已确认：** 年份表示存款年限，总利息手动输入；到期时间为存款日期加年限，总金额为本金加总利息。年利率仅记录，不参与利息计算。

**范围：** 桌面新增存折菜单、分页列表、新增/编辑/删除；成员及存款年份筛选。列表展示成员、存款时间、银行、年份（存款年限）、利率、到期时间、金额、总利息、总金额、备注及操作。后端单独提供 `/api/passbooks`，数据库通过 V9 新增存折表，保留前一项收支字段改动。按当前家庭隔离读取，普通成员仅修改本人创建的记录，管理员可管理当前家庭记录。成员使用稳定的用户 ID，创建与更换成员时校验当前家庭有效成员。范围不包含部署、打包、Web 页面或 Git 提交。
