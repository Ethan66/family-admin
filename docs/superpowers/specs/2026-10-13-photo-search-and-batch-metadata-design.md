# 照片搜索入口与批量分类、评分设计

日期：2026-10-13

## 目标与范围

照片墙顶部原有“分类筛选”“评分筛选”不再常驻工具栏。点击搜索图标后，在搜索框左侧显示这两个筛选按钮，分别按当前目录分类和精确星级筛选照片墙。原工具栏位置改成“批量标记分类”“批量打分”，作用对象仅为当前选中的照片。保持绿色主题和现有照片选择、移动、删除行为。

## 界面与状态

- 搜索图标切换下方搜索区域；区域内依次为分类筛选、评分筛选、文件名或路径输入框。关闭区域不清除已有搜索和筛选条件，再打开时恢复原值。
- 分类筛选继续列出当前目录的分类集合；评分筛选继续提供“全部评分”和 1–5 星精确筛选。两项选中值仍显示在各自按钮旁。
- 工具栏原筛选位置放两个图标按钮：批量分类和批量评分。未选照片或有互斥操作进行时禁用。点击后就地展开选项，不打开模态弹窗。
- 批量分类可选择当前目录已有分类，或输入新分类后确认；该分类追加到每张选中照片，去重并保留原有分类。批量评分选择 1–5 星，覆盖每张选中照片的原评分。两者互不修改标题、文件名、目录、日期、说明等字段。

## 保存与失败处理

复用现有 `saveResourceMetadata` 桌面命令，按选中顺序逐张保存，避免新建跨前后端批量接口。每次根据最新索引取得照片现有资料；没有资料时沿用单张编辑默认值。仅对分类或评分字段做本次变更。保存成功后同步最新索引并从选中集合移除该照片；保存失败的照片保持选中，汇总提示成功与失败数量，可直接重试。家庭切换或资源类型切换时停止继续处理，避免越过当前家庭边界；批量处理期间禁用冲突操作。

## 验收与验证

1. 搜索图标打开的区域中，筛选按钮位于输入框左侧；原工具栏位置是批量操作，不再承担筛选职责。
2. 分类和评分筛选仍按现有规则工作，关闭并重开搜索区域不丢失条件。
3. 无选中照片时批量按钮不可用；选中多张后，追加分类或覆盖评分只影响所选照片，原有其他资料保留。
4. 部分保存失败时，成功、失败数量准确，失败照片仍选中；单张右侧信息和照片墙索引随成功保存更新。
5. 测试放在 `desktop/src/test`，覆盖筛选入口、批量分类、批量评分、空选择和部分失败；执行相关组件测试与类型检查。无需桌面打包或全项目测试。

## 不在本次范围

不更改 JSON 文件格式、照片目录与文件名，不新增 Rust 命令，不修改 Web 和 Java 后端。
