# 照片移动到子文件夹

- 顶部提供“移动已选照片”图标，右侧照片信息提供单张“移动到子文件夹”按钮，二者均在按钮旁展开同一种下拉面板，不使用弹窗。
- 下拉面板的输入框实时筛选已有子文件夹。点击匹配结果立即移动；按回车时，有匹配结果则移动到第一项，没有匹配结果则以输入名称创建子文件夹并移动。输入为空不创建。
- 新建位置默认是左侧当前选中的照片目录；若处于“全部照片”，默认第一个已登记照片根目录。面板中可调整新建位置，避免多根目录时误建。
- 目标仅限当前家庭已登记的照片根目录内。可选择已有子文件夹，或在已登记目录下新建一级子文件夹；不允许直接移到根目录。
- Rust 在操作前验证所有来源和目标、检查重名，禁止覆盖。批量移动以一次操作执行；任何移动或 JSON 写入失败，尝试将全部已移动文件恢复原位，索引保持旧值。新建的空目录在失败时尝试清理。
- 成功后更新照片路径、资源 ID、原有照片资料键及目录树索引。界面清除旧选择，提示成功并显示更新后的索引。
- 文件名与扩展名不变；照片标题、分类、评分等资料保持不变，旧 JSON 的 `album` 字段同步为目标子文件夹名。若跨磁盘移动无法由系统原子改名完成，操作报错并保持原文件。
