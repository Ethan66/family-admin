# 照片目录树与折叠导航设计

日期：2026-10-11

## 目标与范围

照片管理页参考用户提供的桌面图库截图，左侧展示真实本地目录树；登录后的全局导航收窄为图标栏。此阶段仅改变目录读取、页面导航和照片筛选，不创建、重命名或移动照片与目录，不修改照片资料的相册字段语义，也不重做右侧详情。

## 页面布局

- 全局导航在所有登录后页面保持窄栏，仅显示各入口图标、品牌标记及必要的账户操作图标；悬停或键盘聚焦显示菜单名称，当前入口有可见选中态。保留家庭切换、密码修改、退出登录的可达性。登录页不变。
- 照片管理内容区左侧增加独立目录树，右侧为现有照片网格。树顶部提供“全部照片”；照片页顶部保留搜索、添加照片目录、重新扫描和批量操作，移除原来基于 JSON `album` 字段的分类筛选标签。
- 目录节点显示文件夹名称与其自身及所有后代的照片总数。同名文件夹以所在层级区分，悬停可查看完整本地路径。窄窗口下目录树与图库分别滚动，不遮挡全局导航。

## 目录与筛选行为

- 每个已登记的照片扫描根目录是一个顶层节点，扫描器递归记录其所有真实子文件夹，包括空文件夹；继续跳过符号链接。无权限访问的目录沿用扫描警告，不伪造节点。
- 点击节点名称选中目录，图库显示该目录及其所有后代目录中的照片；点击展开箭头只展开或折叠，不改变筛选。“全部照片”显示当前家庭所有照片。所选目录和展开状态在当前页面会话中保持。
- 目录筛选与现有关键词/全局搜索叠加。切换目录清空照片勾选，避免批量删除隐藏在其他目录中的已选照片。切换家庭清空目录筛选及展开状态，绝不复用上一个家庭的目录数据。
- 重新扫描更新照片与目录索引；若当前选中目录已不存在，则回到“全部照片”。若目录仍存在，保持当前筛选。扫描失败保留已显示的旧索引并展示错误。

## 数据与兼容性

- Rust 扫描结果增加照片目录路径集合，写入当前家庭本地 JSON 索引；前端依据根目录、目录路径和照片路径构建树与计数。目录项以完整路径作为稳定键，避免多根目录下同名文件夹冲突。
- 新索引字段提供反序列化默认值。旧 JSON 在首次重新扫描前，可从已索引照片路径补出非空目录；空目录在重新扫描后出现。此阶段不根据 JSON `album` 字段生成树，也不把目录选择写入该字段。
- 照片资源访问和删除继续使用现有家庭索引校验；目录树仅用于展示和前端筛选，不扩大文件系统操作权限。

## 验证

- Rust 定向测试：多层目录、空目录、多扫描根、同名目录、符号链接跳过及旧索引兼容。
- Vue 定向测试：导航图标及提示、树展开/折叠、父目录包含后代、空目录、搜索叠加、切换目录/家庭后的选择清理。
- 运行桌面端类型检查和受影响测试；因扫描索引与全局布局均有变动，再运行桌面生产构建。此阶段不做桌面安装包打包或真实照片移动测试。

## 暂不处理

相册编辑对应实体文件夹的创建/移动、虚拟多文件夹归属、右侧详情面板、HEIC 支持、标签和评分均留待后续单独确认。现有照片卡片的相册资料标识暂保持原逻辑，因此它不代表目录树节点。
