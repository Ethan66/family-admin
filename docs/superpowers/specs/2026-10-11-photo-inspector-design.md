# 照片管理三栏与信息面板设计

## 已确认范围

- 沿用桌面端现有浅灰背景和绿色主题；照片页参照 `photo-layout-v2.html`，左侧目录树、中间密集照片墙、右侧固定信息面板。
- 全局顶部移除搜索框；已有各业务页面的局部搜索保留。超级管理员的家庭切换由顶栏移到 72px 全局导航栏，点击图标弹出可搜索的家庭选择器；普通家庭用户无此按钮。登录页不变。
- 照片不显示复选框。单击照片切换多选，选中态由绿色边框表示；双击照片打开原有大图预览，双击不得造成两次选择切换。更多菜单的全选、取消选择和批量删除继续可用。
- 右侧面板展示最后选中的照片；没有选中时显示操作提示。面板包含本地缩略图、标题、描述、多个分类标签、0–5 星整数评分，以及文件名、大小、修改日期、所在目录等只读信息。点击保存调用已有照片资料保存接口。分类是 JSON 元数据标签，不改变目录或移动原图。旧 `album` 仍在索引中保留以兼容历史资料，但不再作为卡片角标或主编辑字段。
- 家庭切换、删除照片、切换目录或重扫后，应清理不再有效的选中项和右侧面板。保存失败保留表单并显示错误；成功后使用返回索引更新页面，保留既有标题改名与冲突保护逻辑。

## 数据与兼容

照片 `details` 新增 `categories: string[]` 与 `rating: number | null`。Rust 使用 `serde(default)` 读取旧索引；分类去重、去空白，评分限 0–5 的整数。写入当前家庭原有的本地 JSON 文件，不触及其他家庭索引。

## 验证

- Rust：旧 JSON 反序列化、新字段保存与无效评分拒绝。
- Vue：单击多选、双击预览、无复选框、右侧保存、家庭切换入口；现有批量删除与目录筛选回归。
- 类型检查与桌面前端构建；不打包桌面安装程序。
